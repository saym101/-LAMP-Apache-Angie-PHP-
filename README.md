# LAMP/LEMP Installer

![Version](https://img.shields.io/badge/version-4.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Debian%2FUbuntu-orange)

Автоматизированный интерактивный скрипт для установки и базовой настройки веб-стека на Debian/Ubuntu:

- Angie + PHP-FPM;
- Apache + PHP-FPM;
- MariaDB с первичной безопасной настройкой root-пароля;
- тестовая страница и скрытый `phpinfo()`;
- выпуск SSL-сертификатов Certbot для домена или публичного IPv4;
- резервное копирование конфигурации перед сменой веб-сервера.

## Поддержка

Проверенные версии: Debian 12 (Bookworm) / 13 (Trixie), Ubuntu 22.04 / 24.04 LTS, 25.04, 25.10, 26.04 LTS. Другие версии не тестируются.

### Версия PHP и модули

Версия PHP не зашита в скрипт и не спрашивается у админа — при первой установке веб-сервера автоматически ставится та версия, под которую фактически настроен текущий релиз дистрибутива (та, что тянет штатный метапакет `php-fpm`). На уже настроенной системе, где PHP уже стоит, скрипт эту версию не трогает вообще — просто использует то, что уже установлено.

Сторонний репозиторий (Sury на Debian, `ppa:ondrej/php` на Ubuntu) при этом всё равно подключается заранее, с пониженным приоритетом apt (pin 100 против стандартных 500) — чтобы штатную версию не могло случайно подменить пакетом оттуда при обычном `apt upgrade`, но при этом можно было в любой момент поставить другую версию одной командой: `apt install php8.4-fpm` (или любую другую), без повторной возни с ключами и списками репозиториев.

Модули PHP выбираются чек-листом (whiptail, если доступен — пробел отмечает, Enter подтверждает; иначе ставится набор по умолчанию без диалога). `php-fpm` и `php-common` ставятся всегда, а по умолчанию отмечены модули под WordPress/DLE (`mysql`, `xml`, `curl`, `gd`, `mbstring`, `zip`, `intl`, `bcmath`, `imagick`); в списке также доступны `soap`, `ldap`, `sqlite3`, `redis`, `memcached`, `apcu`, `gmp` — по умолчанию выключены.

Angie подключается из `download.angie.software` под реальные `$ID/$VERSION_ID/$VERSION_CODENAME`. Апстрим не всегда успевает собрать пакеты под самые свежие промежуточные релизы Ubuntu (25.04/25.10) — в этом случае скрипт откатывает добавленный репозиторий и завершится понятной ошибкой; используйте Apache как альтернативу.

Для IP-сертификатов Let's Encrypt нужен Certbot 5.3+ с поддержкой `--ip-address` и `--preferred-profile shortlived`. Если системный пакет Certbot старее, пункт IP-сертификата завершится понятной ошибкой и попросит обновить Certbot.

## Быстрый старт

```bash
sudo bash lamp.sh
```

После запуска выберите в меню:

1. `Установить Angie + PHP` — версия ставится штатная, дальше спросит только модули;
2. `Установить Apache + PHP` — версия ставится штатная, дальше спросит только модули;
3. `Установить MariaDB`;
4. `Настроить SSL (Certbot)`.

## Важные файлы

- Лог запуска: `lamp_YYYY-MM-DD.log` в каталоге, из которого запущен скрипт.
- Бэкапы конфигурации: `/backups/web-lamp/`.
- Состояние скрипта: `/var/lib/lamp-setup/`.
- Пароль MariaDB root: `/root/mariadb_credentials.txt`.
- Подсказки cron для Certbot: `/root/certbot_cron.txt`.
- Корень сайта: `/var/www/html`.

## Безопасность

Скрипт создаёт тестовую страницу и файл `phpinfo()`. После проверки удалите их через пункт меню `Удалить тестовые файлы`, потому что `phpinfo()` раскрывает данные о системе и PHP-модулях.

Перед заменой Apache на Angie или Angie на Apache скрипт предлагает создать архив текущей конфигурации. Пользовательские сайты и нестандартные виртуальные хосты всё равно стоит дополнительно сохранить вручную.

## Что делает скрипт

- Проверяет поддерживаемую ОС и устанавливает базовые зависимости.
- Ставит штатную для этого релиза ОС версию PHP, даёт выбрать модули чек-листом, заранее подключает сторонний репозиторий PHP с пониженным приоритетом (на будущее, для других версий) и репозиторий Angie при выборе этого веб-сервера.
- Настраивает PHP-FPM socket для `www-data`.
- Создаёт базовый virtual host для выбранного веб-сервера.
- Настраивает безопасные заголовки и отключает лишнюю выдачу версии PHP.
- При активном UFW предлагает открыть порты `80/tcp` и `443/tcp`.
- Для MariaDB генерирует случайный root-пароль и сохраняет его в файл с правами `600`.

## Ограничения

- Скрипт не переносит существующие сайты и сложные virtual host конфигурации.
- SSL по домену требует корректной DNS A/AAAA-записи на сервер.
- SSL по IP требует публичный IPv4, открытый порт 80 и свежий Certbot.
- Автообновление Certbot не записывается в crontab автоматически: готовая строка сохраняется и выводится на экран.
